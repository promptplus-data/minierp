## 1. Background และเป้าหมาย

ร้านค้าวัสดุก่อสร้างในเครือข่าย Prompt Plus ส่วนหนึ่งยังใช้บิลมือ อีกส่วนมีโปรแกรมขาย/บัญชีของตัวเอง ทั้งสองกลุ่มต้องคีย์คำสั่งซื้อจาก Prompt Plus ซ้ำ และ SCG ไม่เห็นข้อมูลขายออกของร้าน SCG จึงจะทำ ERP ให้ร้านใช้ฟรี เป็นแอปแยกที่เข้าจาก Prompt Plus ได้

| เป้าหมายธุรกิจ | ตัวชี้วัดที่เสนอ (ต้องตกลงเป้าตัวเลข) |
| --- | --- |
| ร้านสั่งซื้อผ่าน Prompt Plus มากขึ้น | ยอดสั่งต่อร้านต่อเดือนของร้าน pilot เทียบก่อน/หลัง go-live |
| SCG ได้ข้อมูลขาย ซื้อ สต็อกของร้าน ตามสัญญาที่ร้านเซ็น | % ร้านที่ส่งข้อมูลครบทุกวัน · % บิลจริงที่บันทึกในระบบ (เป้า ≥ 80% ตาม gate go-live) |
| ยกระดับการบริหารร้าน | ความคลาดเคลื่อนสต็อกจากการนับ · เวลาปิดงบส่งนักบัญชีต่อเดือน |
| เชื่อมสมาชิก SCG Family ที่หน้าร้าน | จำนวนบิลที่ผูก SCG Family ID และคูปองที่ใช้ต่อเดือน |

กำหนดการ: go-live pilot 10 ร้าน เป้า 1 มิ.ย. 2027 ห้ามเกิน 30 มิ.ย. 2027 · ร้าน pilot จด VAT ทุกร้าน · ขยายปีละ 50–100 ร้าน

- ล็อกราคาโครงการแบบมีวันหมดอายุ, เงินประกันผลงาน
- reorder → Prompt Plus, จัดรอบรถ, POS offline, lot/วันหมดอายุ, โปรโมชันของร้านเอง
- API connector กับโปรแกรมบัญชี, e-Tax Invoice, บันทึกบิลผ่าน LINE (น้องพีพี)
- pipeline ส่งข้อมูลเข้า SCG data platform (ทีม Data ของ SCG ทำ)
- การสร้างโปรโมชัน/คูปองและการคำนวณคะแนนสะสม (เป็นหน้าที่ของ SCG Family)

- hosting และ support หลัง hypercare (งบแยก)
